# Информационная веб-система аренды VPS-сервера "VPS Manager"

Информационная веб-система аренды виртуальных серверов (VPS), ориентированная на студентов IT-специальностей, начинающих разработчиков и малый бизнес. Система позволяет зарегистрироваться за минуту, подобрать сервер через понятный конфигуратор без технического жаргона и получить доступ к нему по SSH в течение нескольких минут после оплаты.
