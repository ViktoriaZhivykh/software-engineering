# Информационная веб-система аренды VPS-сервера "VPS Manager"

Информационная веб-система аренды виртуальных серверов (VPS), ориентированная на студентов IT-специальностей, начинающих разработчиков и малый бизнес. Система позволяет зарегистрироваться за минуту, подобрать сервер через понятный конфигуратор без технического жаргона и получить доступ к нему по SSH в течение нескольких минут после оплаты.

## Основные возможности

### Для гостя

- Просмотр каталога тарифных планов с характеристиками
- Интерактивный конфигуратор сервера: выбор CPU, RAM, SSD и операционной системы
- Динамический пересчёт итоговой стоимости при изменении любого параметра
- Регистрация и вход в систему по email и паролю

### Для клиента

- Выбор тарифа и настройка конфигурации сервера перед оформлением заказа
- Оформление заказа с выбранной конфигурацией и переход к оплате
- Автоматическая активация виртуального сервера не позднее чем через 5 минут после успешной оплаты
- Личный кабинет со списком всех активных и ранее созданных серверов
- Просмотр статуса каждого сервера: активен, остановлен, запускается
- Управление сервером: запуск, остановка, перезагрузка
- Просмотр базовой статистики потребления ресурсов (загрузка CPU и RAM)
- История заказов и платежей
- Редактирование профиля и смена пароля

### Для администратора

- Управление каталогом тарифов: добавление, редактирование, удаление
- Просмотр списка всех зарегистрированных пользователей
- Просмотр всех заказов клиентов
- Принудительная остановка и перезагрузка любого сервера клиента в экстренных случаях
- Просмотр системных логов и статистики использования

### Особенности реализации

- Адаптивный интерфейс: корректная работа на мобильных (от 375 px), планшетах (от 768 px) и настольных экранах (от 1280 px)
- Время ответа API не превышает 500 мс для 95 % запросов
- Пароли хранятся в виде bcrypt-хешей, доступ к административной панели разграничен по ролям
- Сохранение введённых данных конфигуратора в локальном хранилище браузера при потере соединения
- Логирование всех критических действий администратора для последующего аудита
