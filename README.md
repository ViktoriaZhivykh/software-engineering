# Информационная веб-система аренды VPS-сервера "VPS Manager"

## Назначение

VPS Manager — информационная веб-система аренды виртуальных серверов (VPS), ориентированная на студентов IT-специальностей, начинающих разработчиков и малый бизнес. Система позволяет зарегистрироваться за минуту, подобрать сервер через понятный конфигуратор без технического жаргона и получить доступ к нему по SSH в течение нескольких минут после оплаты.

## Пользователи системы

- **Гость** — неавторизованный посетитель, который знакомится с тарифами и использует конфигуратор для расчёта стоимости.
- **Клиент** — авторизованный пользователь, который арендует виртуальные серверы и управляет ими из личного кабинета.
- **Администратор** — сотрудник платформы, который управляет каталогом тарифов, пользователями и серверами клиентов в экстренных случаях.

## Основные возможности

- Интерактивный конфигуратор с динамическим пересчётом стоимости: выбор CPU, RAM, SSD и операционной системы
- Оформление заказа и автоматическая активация виртуального сервера не позднее чем через 5 минут после оплаты
- Личный кабинет клиента: список серверов, их статусы и управление (запуск, остановка, перезагрузка)
- Просмотр статистики потребления ресурсов сервера (загрузка CPU и RAM)
- История заказов и платежей, редактирование профиля и смена пароля
- Административная панель: управление тарифами, пользователями и заказами, просмотр системных логов
- Адаптивный интерфейс и защита данных: bcrypt-хеширование паролей, разграничение доступа по ролям, логирование действий администратора
